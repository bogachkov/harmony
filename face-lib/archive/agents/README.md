## Honest read on the crew (post-roadmap-recalibration, Q1-W4)

The agentic-team experiment didn't work the way Gary hoped. The engine wins from days 1-3 happened because each step had a clear visible problem; not because of the multi-role structure. Single-agent with Gary closer to the renders likely produces the same outcome with less ceremony.

What the structure actually added: Pascal score inflation, Claudia plan bloat, Bob relaying instead of looking, roles inventing their own vocabulary the team then optimized for.

Some roles pull weight, some are theater. This index file is the start of reviewing which is which.
